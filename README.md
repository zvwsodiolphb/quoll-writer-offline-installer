# Quoll Writer — Free Offline Installer

![Category](https://img.shields.io/badge/Writing_Software-blue?style=flat-square)

## About

Quoll Writer is a free, open-source writing application for Windows designed to minimize distractions and help writers focus on their work. Features include a full-screen distraction-free mode, a chapter/section organizer, writing targets, character and location notes, and a problem word highlighter. Quoll Writer stores everything in a project file for easy backup and portability.

## Common Problems & Limitations

- **Windows Only** — No macOS or Linux version
- **Limited Export** — Export options less comprehensive than commercial writing tools
- **Development Status** — Updates infrequent compared to actively maintained alternatives
- **Collaboration** — No real-time collaboration features
